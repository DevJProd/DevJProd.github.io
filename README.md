# Javier Agüera — Personal Portfolio

Personal portfolio site of **Javier Agüera**, C/C++ embedded &amp; real-time software
engineer (defense, railway) and blockchain infrastructure engineer.

Live at **https://devjprod.github.io**

## Stack

- Static HTML / CSS / vanilla JavaScript — no build step, no dependencies
- Dark "developer" theme, fully responsive, accessible (skip link, focus states,
  reduced-motion support, progressive enhancement)
- Hosted on GitHub Pages

## Structure

```
index.html   – markup and content
index.css    – theme, layout and components
index.js     – nav, scroll reveal, back-to-top
images/      – project shots, portrait, icons
fonts/       – (legacy local fonts; UI uses Google Fonts)
```

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
